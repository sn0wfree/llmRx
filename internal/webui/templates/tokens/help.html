OpenAI 兼容 API 端点使用指南

API 基础地址

所有 OpenAI 兼容端点都通过此地址调用。如果部署在反向代理后面且当前显示的协议不对，请将 http 改为 https。

{{.BaseURL}}/v1

cURL 非流式调用

最常见的命令行调用方式，等待完整响应后一次性返回。

curl -X POST {{.BaseURL}}/v1/chat/completions \
  -H "Authorization: Bearer sk-<your-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MiniMax-M3",
    "messages": [
      {"role": "user", "content": "你好"}
    ]
  }'

cURL 流式调用（SSE）

用 -N 禁用 curl 缓冲，配合 stream: true 开启 SSE 打字机效果。 

curl -N -X POST {{.BaseURL}}/v1/chat/completions \
  -H "Authorization: Bearer sk-<your-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MiniMax-M3",
    "stream": true,
    "messages": [
      {"role": "user", "content": "写一首关于中秋的诗"}
    ]
  }'

Python (openai SDK)

直接用 openai 官方 SDK，base_url 指向本服务即可，其它参数与官方 OpenAI 用法完全一致。 

from openai import OpenAI

client = OpenAI(
    api_key="sk-<your-token>",
    base_url="{{.BaseURL}}/v1"
)

resp = client.chat.completions.create(
    model="MiniMax-M3",
    messages=[{"role": "user", "content": "你好"}]
)
print(resp.choices[0].message.content)

字段含义

字段 说明
名称 内部标识，仅用于在管理界面区分 token，不影响 API 调用。
关联 Plan 绑定计费计划，会在 channel 价格之上叠加 plan 的 markup_ratio。
RPM 每分钟请求数上限。0 = llmRx 不限（上游 provider 仍可能有自己的限流）。
TPM 每分钟 token 数上限（输入 + 输出）。0 = llmRx 不限。
默认模型集 组合模型的名称 + 模式 + 成本策略。请求 model:"auto" 时从这个集合自动挑选通道。
IP 白名单 每行一个 IP 或 CIDR（如 192.168.1.0/24）。留空 = 不限；* = 通配。
过期天数 0 = 永不过期；否则按创建时间 + N 天后失效。
启用 勾选时 token 可用；取消后所有使用该 token 的请求会返回 403。

使用 model:"auto" 智能路由

将 model 设为 auto 时，llmRx 会按 token 的默认模型集自动挑选一个最合适的通道（基于成本、延迟、健康度）。无需关心上游具体模型名称。 

curl -X POST {{.BaseURL}}/v1/chat/completions \
  -H "Authorization: Bearer sk-<your-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "auto",
    "messages": [{"role": "user", "content": "你好"}]
  }'

常见错误码

HTTP code 原因
401 missing_authorization / invalid_authorization Authorization 头缺失或格式不对（必须为 Bearer sk-...）。
403 invalid_token token 不存在或已禁用。
403 token_expired token 已过期。
403 model_not_allowed 请求的 model 不在该 token 的模型白名单内。
403 ip_not_allowed 客户端 IP 不在该 token 的 IP 白名单内。
429 rate_limited 触发 RPM / TPM 上限。等待重置或调高限额。
402 budget_exceeded 关联 Plan 的 USD 预算已用完。
503 no_channel 没有可用的 channel 路由该模型（检查 channels 配置和模型白名单）。
